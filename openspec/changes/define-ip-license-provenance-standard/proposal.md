# Proposal: Define IP License Provenance Standard

## Intent

Add stage 42: a one-person-company standard for open source license governance, third-party content/source provenance, AI-generated output rights, dataset/eval provenance, NOTICE/attribution, and release IP review.

## Scope

- Define required `ip-rights/` artifacts for each production target that uses, distributes, publishes, trains/evaluates on, or exposes code/content/data/assets/models/prompts generated by AI or obtained from third parties.
- Cover source registers, license policies, AI output policies, NOTICE/attribution, and IP reviews.
- Connect Go/Kratos/sqlc/gRPC dependencies and generated code, Vite assets and public UI, AI prompt/eval/dataset/RAG content, customer content, and release gates.
- Create a reusable Codex skill and local verifier.

## Out of Scope

- Formal legal advice, fair use opinions, copyright registration, trademark registration, patent strategy, litigation, takedown handling, or customer indemnity negotiation.
- Replacing security/supply-chain, maintenance/dependency, AI coding workflow, trust policy, dataset/eval, or content safety standards.
- Full OSPO, enterprise license-compliance platform, CLA/DCO workflow, or commercial legal repository.

## Sources

- The Mythical Man-Month, small project management, The Cathedral and the Bazaar, Producing Open Source Software, Software Engineering at Google dependency management.
- SPDX Specification and License List, REUSE Specification, OSI license list and Open Source Definition.
- npm package license field, Go module/package ecosystem, GitHub Dependency Review.
- U.S. Copyright Office AI guidance/report, USPTO IP basics, WIPO generative AI and IP guidance.
- OpenAI Terms/Services Agreement/Usage Policies.
- Creative Commons, Open Data Commons, Hugging Face dataset/model card license metadata.

## Human Attention

Keep human judgment only for:

- AGPL/GPL/LGPL/MPL/EPL/CDDL/ODbL/CC-BY-SA/CC-BY-NC/custom/proprietary/no-license/unknown sources;
- copied code/content from web, chat, issue trackers, Stack Overflow, papers, books, docs, competitors, customers, or model outputs;
- user/customer content used for eval, training, demos, marketing, docs, screenshots, examples, or case studies;
- claims that AI output is exclusively owned, copyright-registerable, fully original, 100% commercial-safe, or free of third-party risk;
- public release containing third-party content, marks, people, protected characters, living-artist style, datasets, models, or license-limited sources;
- incomplete NOTICE/source offer/attribution for SDKs, CLIs, containers, frontend bundles, datasets, models, templates, or customer deliverables.
