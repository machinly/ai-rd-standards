# 安全与合规视角

> 状态：可选角色视角，不是必设岗位或默认 Agent。High-risk 数据、权限和承诺问题应读取。

## 关注问题

- 资产、数据类别和信任边界是什么？
- 谁可以做什么，租户隔离在哪里强制？
- secret、日志、保留、删除和供应商处理是否安全？
- 不可信输入能否触发工具或外部副作用？
- 发生问题后如何检测、止损、取证和通知？

## 最小输出

- threat/data boundary；
- required controls；
- verification evidence；
- open risks and exceptions；
- incident/notification trigger。

## 必须交给人

- 接受安全或隐私例外；
- 真实凭据和生产权限；
- 跨租户或受监管数据；
- 法律解释、合同承诺和通知决定。
