# 两轮 Review Rubric

每完成一个规范段落、OpenSpec artifact 集合或实现里程碑后使用。

## Review A：一人可执行性

简短回答：

- 一个人是否能执行，不需要并行角色？
- 它是在降低认知负担，还是增加仪式？
- 下一步是否明显？
- 中断后是否能从已入库 artifacts 恢复？
- 是否有重复劳动适合做成 skill、script 或 template？

通过条件：这一段能被一个人在一个专注工作块内执行，或明确指出哪些内容需要推迟。

## Review B：产品 / 工程 / 运维风险

简短回答：

- 是否避免了过早复杂化？
- 是否定义了测试、eval 或人工验收标准？
- 是否有生产健康或用户影响信号？
- 是否处理了数据、安全、隐私和回滚风险？
- 最小安全下一步是什么？

通过条件：下一步有验证方法，并且没有隐藏重大不可逆决策。
